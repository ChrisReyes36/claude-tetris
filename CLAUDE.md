# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Tetris en JavaScript vanilla + HTML5 Canvas (README y UI en español). No hay build, dependencias, linter ni tests: tres archivos estáticos (`index.html`, `style.css`, `game.js`). Para ejecutar, abrir `index.html` en el navegador o servir el directorio con cualquier servidor estático (p. ej. `python -m http.server`).

## Arquitectura de `game.js`

Todo el juego vive en un único script con estado global a nivel de módulo (`board`, `current`, `next`, `score`, `lines`, `level`, `paused`, `gameOver`, `dropInterval`, etc.), declarado en una sola línea y asignado en `init()`.

- **Tablero**: matriz `ROWS × COLS` (20×10) de enteros. `0` = vacío; `1–9` = índice de pieza, usado tanto en `PIECES` (matrices de forma) como en `COLORS` (mismo índice). Al añadir una pieza hay que actualizar `PIECES`, `COLORS` y `COLORS_LIGHT`. La pieza 8 es la tuerca (3×3 con hueco central real: su fila central no se puede limpiar). La pieza 9 es la bomba (1×1, ítem especial): `randomPiece` la sortea aparte con `BOMB_CHANCE` (10 %), debe seguir siendo el último índice de `PIECES`, y nunca se fusiona con el tablero (`lockPiece` llama a `explode()` en vez de `merge()`, que borra el área 3×3 sin gravedad y da `BOMB_POINTS * level` por bloque destruido). `drawBlock` la dibuja como círculo con mecha.
- **Pieza**: objeto `{ type, shape, x, y }`; `shape` es una matriz cuyos valores no cero son el índice de color. La rotación (`rotateCW`) genera una matriz nueva; `tryRotate` aplica *wall kicks* horizontales `[0, -1, 1, -2, 2]`.
- **Bucle**: `loop(ts)` (requestAnimationFrame) acumula `dropAccum` y baja la pieza cuando supera `dropInterval`; `dropInterval = max(100, 1000 - (level-1)*90)`, recalculado en `clearLines`. Pausa y game over cancelan el frame con `cancelAnimationFrame(animId)`; `init()` reinicia todo el estado (también lo usa el botón Reiniciar).
- **Ciclo de pieza**: `lockPiece()` = `merge()` → `clearLines()` → `spawn()`. `spawn()` promueve `next`, genera una nueva y llama a `endGame()` si la nueva pieza colisiona al aparecer.
- **Colisión**: `collide(shape, ox, oy)` es la única función de detección; la usan movimiento, rotación, ghost (`ghostY`) y spawn.
- **Puntuación**: líneas `LINE_SCORES[n] * level`; soft drop +1 por celda, hard drop +2 por celda; nivel = `floor(lines/10)+1`.
- **Render**: `draw()` repinta todo cada frame (rejilla, tablero, pieza fantasma con alpha 0.2, pieza actual y `drawExplosions()`, que pinta destello y chispas de las entradas de `explosions`, añadidas por `explode()` y expiradas por tiempo con `EXPLOSION_MS`); `drawNext()` solo se llama en `spawn()`. Ambas usan `drawBlock(context, x, y, colorIndex, size, alpha)`.
- **DOM**: `game.js` depende de los IDs de `index.html` (`board`, `next-canvas`, `score`, `lines`, `level`, `overlay`, `overlay-title`, `overlay-score`, `restart-btn`); el overlay se muestra/oculta con la clase `hidden`. El tamaño de los canvas (300×600 y 120×120) está en el HTML y debe coincidir con `COLS/ROWS/BLOCK`.
- **Tema claro/oscuro**: `style.css` define variables en `:root` (oscuro) y `[data-theme="light"]`. `applyTheme(name)` en `game.js` fija `data-theme` en `<html>`, guarda en `localStorage` (`tetris-theme`), lee del CSS los colores que usa el canvas (`--grid`, `--block-highlight`, `--ghost-alpha`), elige la paleta (`COLORS` o `COLORS_LIGHT`, mismos índices) y repinta `drawNext()`/`draw()`. Al añadir una pieza hay que actualizar también `COLORS_LIGHT`. El botón `#theme-toggle` hace `blur()` tras el clic para que `Space` no lo active.
- **Menú de pausa**: `P`/`Escape` llaman a `togglePause()` → `openPauseMenu()` / `resume()`, que muestran/ocultan el overlay `#pause-menu` (separado de `#overlay`, que es solo game over). Contiene Reanudar (`#resume-btn`), Reiniciar (`#pause-restart-btn`, llama a `init`), Ver controles (`#controls-btn` alterna `#pause-controls`) y el selector `#start-level` (1–10). El nivel inicial (`startLevel`) se guarda en `localStorage` (`tetris-start-level`), lo usa `init()` y el nivel pasa a ser `startLevel + floor(lines/10)`; no afecta a la partida en curso. `intervalFor(level)` calcula `dropInterval`.
- **Records**: `localStorage['tetris-records']` = `{ top: [{name, score, lines, combo}], bestCombo, bestLines }` (top 5 por puntuación). `loadRecords`/`saveRecords` con `try/catch`; `recordRank(score)` devuelve la posición o `-1` si no entra. Combo = bloqueos consecutivos que limpian líneas (calculado en `clearLines`, solo se registra). Al cargar no se llama a `init()`: `showStart()` muestra el overlay (solo sobre el tablero, dentro de `.board-wrap`) con título TETRIS y botón "Jugar"; la tabla vive siempre visible en el panel izquierdo `#records` (`started` es `false` hasta entonces y el `keydown` lo ignora). En `endGame()` se actualizan los máximos históricos y, si entra al top, se muestra `#name-form`; `renderRecords(idx)` resalta la fila nueva. IDs extra: `name-form`, `name-form-msg`, `player-name`, `records`, `records-list`, `best-combo`, `best-lines`, `reset-records`. El `keydown` ignora eventos cuyo target es un `<input>`.
- **Input**: un único listener `keydown` (flechas, `X` rotar, `Space` hard drop, `P`/`Escape` pausa). Con el menú abierto (o en game over) el juego no procesa teclas y las registra en `heldKeys`; tras reanudar se ignoran hasta su `keyup`, para que una tecla mantenida no mueva la pieza. `resume()` e `init()` hacen `blur()` del elemento activo para que `Space` no pulse un botón.
- **Skins**: `SKINS` (en `game.js`) registra `retro`, `neon`, `pastel` y `pixel`; cada una aporta `colors`/`colorsLight` (mismos índices que `COLORS`) y `cell(ctx, px, py, size, color)`, la función que dibuja un bloque normal (la bomba la dibuja siempre `drawBlock`, con glow si `skin.glow`). `applySkin(name)` fija `data-skin` en `<html>` (Neon sobrescribe variables CSS para forzar fondo negro), guarda en `localStorage` (`tetris-skin`) y llama a `refreshCanvasStyle()`, que también usa `applyTheme` (relee variables CSS, elige paleta según tema+skin y repinta). El selector es una rejilla de botones `.skin-btn[data-skin]` en el panel lateral (con miniatura dibujada por `drawSkinPreviews()` y `aria-pressed` para la activa); hacen `blur()` tras el clic. Al añadir una pieza hay que actualizar también `COLORS_NEON`, `COLORS_PASTEL` y `COLORS_PASTEL_LIGHT`.
